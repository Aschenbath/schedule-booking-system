# 演示脚本（≤ 5 分钟）

## 录制前准备（不计时）

```bash
npm install
npm test                                   # 先跑一遍，录屏时直接展示结果：30 passed
npm run reset                              # 清库，让种子日程按下面的 NOW 对齐
# 大模型可选：.env 里写 LLM_PROVIDER=openai + LLM_BASE_URL/LLM_API_KEY/LLM_MODEL，npm run probe 通过再启动
```

用覆盖时间启动（周三 09:44，第 0 天 10:00 有「周经营例会」，提醒提前 15 分钟，所以开始录制约 1 分钟后会自动弹提醒）：

```bash
# PowerShell
$env:NOW="2026-09-23T09:44:00"; npm start
# bash
NOW=2026-09-23T09:44:00 npm start
```

打开 http://localhost:3000 ，右上角选 **刘洋（设计部）**。浏览器再开一个标签页备用（用来展示多标签页不重复弹窗）。

## 备用输入

- 冲突：`明天上午10点在公司开会，主题投标复盘，叫上市场部` → 与 09:30–10:30「设计方案评审」重叠，给出空档。
- 接待：`下周二上午接待一下万科的客户，大概5个人` → 识别来访方、人数，追问具体时刻与地点。
- 饭局：`周五晚上6点半在广州塔请建材商吃饭，4个人，叫上董浩` → 一次说全，默认 2 小时，直接可提交。
- 手机端：浏览器切到手机模拟器，五个页面均为单列布局。

## 提醒时间对不上时

`NOW_MODE=offset` 以进程启动时刻为锚点，启动后时钟正常走。若启动到录制之间隔了太久，重启服务把 NOW 再往前调即可；或者在提醒中心（老板）点「立即检查提醒」。
